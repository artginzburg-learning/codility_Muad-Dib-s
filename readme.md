### Task

Given an array of unknown length where each element is a day number (9999 is as valid as 1 or 30, for example), determine what tickets should you buy (and when) so that the total price is as low as possible.

The function written should get an array described above and return the lowest possible price that you can travel for during the days provided.

So, with input of `[1, 30]`, it should return `4`.
